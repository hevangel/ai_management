# Comics

Horace Chan's comics and cartoons, originally posted on LinkedIn,
presented as a standalone page (not registered in the site's
`content.json`, same as the `LinkedIn/` archive) and linked from the
root page's top navigation.

- `index.html` — the viewer, generated by `tools/build_comics.py`.
  xkcd-style: one comic at a time, First / Prev / Random / Next /
  Latest navigation above and below the image, `#<num>` hash
  permalinks, arrow-key flipping, full archive list at the bottom.
- `comics.json` — the catalog: num, title (first line of the post),
  date (America/Vancouver), caption (full post text), image file,
  and the original LinkedIn post URL.
- `images/` — the comic image files, downloaded from LinkedIn
  (LinkedIn's signed image URLs expire, so the files live here).

## Adding a comic

1. Save the image as `images/<NN>.<ext>` (NN = next number).
2. Append an entry to `comics.json`.
3. Run `python3 tools/build_comics.py` and commit the result.
